# 这里是SqyL的个人MineCraft服务器

V1.0 说明 2024年3月23日13时

MineCraft 版本: 1.19.2 (based on Forge 43.3.0)

查看Mod说明: *./mods.txt*

说明：

本服务器共应用8个内容模组(及若干辅助模组)。

新区域模组：暮色森林、天境

武器模组：天神剑技

移动模组：伊卡洛斯之翼

种田烹饪模组：农夫乐事

剧情冒险模组：帕斯特之梦

身份玩法模组：吸血鬼

BUFF模组：你再造！

祝你玩得开心！
